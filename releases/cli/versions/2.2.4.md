## 🐛 Context-leak fix in cgroup isolation

Fixed a `context.WithTimeout` cancel-function leak in `MaybeIsolateCgroup` (`lib/apply_cgroup_linux.go`).  The cancel function was discarded with `_`; the context leaked until the 1-second timer fired on every invocation.  The cancel is now captured and deferred.  Detected by `go vet -lostcancel`.
